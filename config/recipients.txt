#     multiple aliases with a semicolon ";". You can leave aliases blank

#   - Lines starting with "#" are comments and are ignored.
#   - Blank lines are ignored.
#   - To ADD an organization: just add a new line in this format.
#   - To REMOVE one: delete the line, or put a "#" at the start of it.

# it if you might want it back later.
